A high-performance, isomorphic, and type-safe PowerPoint (`.pptx`) toolkit for TypeScript and JavaScript.

Parse, construct, mutate, template, and serialize OpenXML presentation decks with 100% round-trip fidelity across Node.js, Web Browsers, Cloudflare Workers, Deno, and Bun.

## Key Capabilities

- ⚡ **100% Isomorphic & Zero Native Dependencies**: Runs identically in Node.js, Browsers, Cloudflare Workers, Deno, and Bun. Non-blocking asynchronous decompression powered by `fflate`.
- 📐 **Branded Units & Type Safety**: Physical measurements are strictly typed via branded types (`Inches`, `Points`, `Emu`, `EmuDegree`, `HundredthsPoint`), eliminating coordinate math errors.
- 🎨 **Theme & Typography Engine**: Programmatically customize theme color schemes (`setThemeColors`), font schemes (`setThemeFonts`), and theme display names (`setThemeName`).
- 📑 **Multilevel Bullet Lists**: Full support for hierarchical lists (levels 0 to 8) with automatic bullets, custom indents, and rich inline text modifiers (`bold`, `italic`, `underline`, `strikethrough`, `superscript`, `subscript`).
- 🎯 **Template & Placeholder Replacement**: Load corporate `.pptx` templates, instantiate slides from layouts (`master:cover-1`, `master:title-with-body`), and replace placeholder text by semantic type (`'title'`, `'body'`) or placeholder shape name.
- 📊 **Enterprise Data Tables**: Multi-column tables with custom column widths, headers, alternating row styles, text alignment, and cell padding.
- 🔄 **Perfect Round-Trip Symmetry**: AST generated by `@hokkyss/pptx-reader` can be directly fed to `@hokkyss/pptx-writer` without data loss or corruption.

## Quick Start

### 1. Authoring a Presentation from Scratch

```typescript
import { Presentation, inches, points } from '@hokkyss/pptx';

// 1. Initialize presentation
const pres = Presentation.create({
  title: 'Cloud Architecture Deck',
  author: 'Engineering Team',
});

// 2. Customize Theme
pres
  .setThemeName('Modern Cloud Theme')
  .setThemeColors({
    accent1: '#0284C7', // Sky Blue
    accent2: '#6366F1', // Indigo
  })
  .setThemeFonts({
    major: 'Inter',
    minor: 'Roboto',
  });

// 3. Add Slide with Title & Multilevel Bullets
const slide = pres.addSlide();
slide.setBackground('0F172A'); // Slate 900

slide.addText('Distributed Edge Architecture', {
  bold: true,
  color: '38BDF8',
  fontSize: points(28),
  x: inches(1),
  y: inches(1),
  w: inches(11.33),
  h: inches(0.8),
});

slide.addText([
  { level: 0, text: '1. Event-Driven Runtime Engine' },
  { level: 1, text: '1.1 Microsecond execution at edge locations' },
  {
    level: 2,
    runs: [
      { text: '1.1.1 Sub-millisecond latency profile: O(n' },
      { text: '2', superscript: true },
      { text: ')' },
    ],
  },
  {
    level: 2,
    runs: [
      { text: '1.1.2 Legacy polling protocol: ' },
      { text: 'deprecated', strikethrough: true },
    ],
  },
], {
  x: inches(1),
  y: inches(2),
  w: inches(11.33),
  h: inches(4.5),
});

// 4. Save to disk
await pres.save('cloud_deck.pptx');
```

---

### 2. Loading & Mutating an Existing Template

```typescript
import { readFile } from 'node:fs/promises';
import { Presentation } from '@hokkyss/pptx';

const templateBytes = await readFile('corporate_template.pptx');
const pres = await Presentation.load(templateBytes);

// Instantiate slide using existing layout
const slide = pres.addSlide({
  layout: 'master:title-with-body',
});

// Replace placeholder content
slide.addText('Executive Summary', {
  placeholder: 'title',
});

slide.addText('• Key objective 1\n• Key objective 2', {
  placeholder: 'body',
});

await pres.save('populated_presentation.pptx');
```

### 3. Parsing and Inspecting Presentation AST

```typescript
import { parsePptx } from '@hokkyss/pptx-reader';

const doc = await parsePptx(buffer);

console.log(`Title: ${doc.metadata.title}`);
console.log(`Total Slides: ${doc.slides.length}`);
console.log(`Themes: ${doc.themes.map(t => t.name).join(', ')}`);

for (const slide of doc.slides) {
  console.log(`Slide #${slide.slideNumber} has ${slide.elements.length} elements`);
}
```

## OpenXML Specifications & Schema Standards

This library is engineered strictly against the official Office Open XML (OOXML / ECMA-376) standards and schemas:

| Resource | Specification & Schema Reference | Description |
| :--- | :--- | :--- |
| **ECMA-376 Standard** | [ECMA-376 5th Edition (Part 1)](https://www.ecma-international.org/publications-and-standards/standards/ecma-376/) | Fundamentals & Markup Language Reference for PresentationML and DrawingML. |
| **ISO/IEC Standard** | [ISO/IEC 29500-1:2016](https://www.iso.org/standard/71691.html) | International standard for Office Open XML file formats. |
| **PresentationML Architecture** | [Structure of a PresentationML Document](https://learn.microsoft.com/en-us/office/open-xml/presentation/structure-of-a-presentationml-document) | Package hierarchy, slide masters, slide layouts, and relationship mappings. |
| **DrawingML Theme Engine** | [DrawingML Theme Elements (`<a:theme>`)](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.theme?view=openxml-3.0.1) | Theme elements, color palettes, and font schemes. |
| **Custom Color Palettes** | [DrawingML Color Scheme (`<a:clrScheme>`)](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.colorscheme?view=openxml-3.0.1) | Color scheme definition and `<a:extraClrSchemeLst>` Slide Master custom palette registration. |
| **Theme Typography** | [DrawingML Font Scheme (`<a:fontScheme>`)](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.fontscheme?view=openxml-3.0.1) | Major (Headings / `+mj-lt`) and Minor (Body / `+mn-lt`) font pair mapping. |
| **Charts & Visual Analytics** | [DrawingML ChartSpace (`<c:chartSpace>`)](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.charts?view=openxml-3.0.1) | Bar, Column, Line, Area, Doughnut, Pie, Radar, and Data Point (`<c:dPt>`) schemas. |
| **DrawingML Tables** | [DrawingML Table (`<a:tbl>`)](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.table?view=openxml-3.0.1) | Table grid, row heights, column widths, and cell text body properties. |
